# Green Falls Co. typography

Approved 24 September 2026: Archivo replaces Bricolage Grotesque for brand headings.

- Headings: Archivo Variable, weight 600, width 85%, tracking -0.02em.
- Body and interface: Libre Franklin Variable; retain existing readable sizes and weights.
- Secondary display text uses Archivo at its natural width.
- Use real variable width, never CSS scaleX or a synthetic condensed substitute.
- Fonts are self-hosted via Fontsource with font-display: swap.
- The approved custom logo is artwork, not typeset Archivo. Preserve its letterforms.
